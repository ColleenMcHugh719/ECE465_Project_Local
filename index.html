Abstract and Project Summary

Liver cirrhosis is a serious and progressive disease that significantly affects liver function and overall patient health. Accurate staging is important for treatment planning, prognosis evaluation, and long-term patient monitoring. However, liver disease classification is challenging because many clinical indicators overlap between stages.

In this project, multiple machine learning approaches were explored for multiclass liver disease staging using both structured clinical datasets and medical imaging datasets. Decision Trees, Random Forests, Multilayer Perceptrons (MLPs), and Convolutional Neural Networks (CNNs) were implemented and evaluated in MATLAB. The project compared classification performance, interpretability, feature importance, and the ability of different models to capture nonlinear relationships within clinical and image-based data.

Introduction and Motivation

Liver cirrhosis is a chronic disease characterized by the replacement of healthy liver tissue with scar tissue, resulting in reduced liver functionality and increasing medical complications as the disease progresses. Accurate disease staging is important because treatment strategies and prognosis depend heavily on disease severity.

Traditional diagnosis often depends on combinations of laboratory testing, imaging interpretation, and physician judgment. Machine learning provides an opportunity to analyze multiple clinical variables simultaneously and identify complex relationships between features that may not be obvious using conventional analysis methods.

Related Work

Previous research has demonstrated strong performance for machine learning models on structured liver disease datasets. Prior studies using Random Forest approaches on related cirrhosis datasets reported classification accuracies approaching 99% under highly optimized conditions. However, extremely high performance on small structured medical datasets should be interpreted carefully because strong biomarker correlations, class balancing, and overfitting can influence results.

This project focused not only on classification accuracy, but also on interpretability, feature engineering, feature impact analysis, and the integration of structured clinical records with medical imaging approaches.

Project Scope

Two separate but related machine learning workflows were explored. The first workflow evaluated structured tabular clinical records using Decision Trees, Random Forests, and MLP neural networks. The second workflow explored image-based fibrosis classification using convolutional neural networks and liver ultrasound images.

The long-term objective of the project is a multimodal system capable of analyzing both clinical records and medical imaging data simultaneously in order to provide more comprehensive liver disease assessment and staging support.

Preprocessing Pipeline

  • Removed rows with missing target labels.
  • Restricted classification targets to cirrhosis stages 1–3.
  • Removed non-predictive variables such as ID, N_Days, Drug, and Status.
  • Applied categorical encoding to variables such as sex, ascites, edema, hepatomegaly, and spiders.
  • Performed missing value interpolation and mean replacement for numerical features.
  • Assigned missing categorical values to a separate missing category.
  • Applied z-score normalization using training-set statistics.
  • Split the dataset using a 70% training, 15% validation, and 15% testing partition.

Machine Learning Methods

Decision Tree

The Decision Tree model served as the baseline approach because it is highly interpretable and easy to understand. Tree depth was limited to reduce overfitting while maintaining interpretability.

Random Forest

Random Forest improved performance through bagging and ensemble learning. Both MATLAB’s built-in implementation and a custom from-scratch implementation were explored.

MLP Neural Network

A custom multilayer perceptron neural network was manually implemented using forward propagation, backpropagation, ReLU activation functions, and softmax classification.

CNN Model

The convolutional neural network used multiple convolutional blocks, pooling layers, batch normalization, and softmax classification for fibrosis stage prediction from ultrasound images.

Conclusion and Future Work

This project explored multiple machine learning approaches for liver cirrhosis stage classification using both structured clinical datasets and medical imaging data. Decision Tree, Random Forest, Multilayer Perceptron (MLP), and preliminary CNN-based approaches were evaluated using publicly available liver cirrhosis datasets in MATLAB.

Among the tabular models, Random Forest achieved the highest overall performance with accuracies approaching 89%, while the custom MLP neural network achieved comparable performance near 88%. Feature analysis showed that biomarkers such as bilirubin, albumin, platelets, and prothrombin were among the most important predictors of cirrhosis severity.

Overall comparison of machine learning model performance across the project.

The project also explored CNN-based image classification using liver ultrasound data. Although the imaging pipeline remains under development, the results demonstrated the broader potential of combining structured clinical records with medical imaging analysis for liver disease assessment.

Future work may include larger and more diverse datasets, improved neural network optimization techniques, deeper CNN architectures, transfer learning, and multimodal systems capable of simultaneously analyzing clinical records and medical imaging data for more comprehensive liver cirrhosis staging.
