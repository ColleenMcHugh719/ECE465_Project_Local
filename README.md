# Machine Learning-Based Classification of Liver Disease Stages

This repository contains the materials, code, datasets, and website assets developed for the University at Albany IECE465 Machine Learning for Engineers project focused on liver cirrhosis stage classification using machine learning techniques.

## Repository Structure

### `/static`
Contains website assets and supporting media including:
- Images
- Figures
- Diagrams
- Visualization outputs
- Dataset-related assets

### `/code`
Contains MATLAB implementations and supporting scripts for:
- Decision Tree models
- Random Forest models
- Multilayer Perceptron (MLP) neural networks
- Convolutional Neural Network (CNN) workflows
- Preprocessing and feature engineering

### `/docs`
Contains project documentation including:
- Final report
- Presentation materials
- Posters
- Additional project documentation

### `index.html`
Main GitHub Pages website file for the project.

## Project Overview

This project explores machine learning approaches for liver cirrhosis stage classification using both structured clinical data and medical imaging workflows. Models explored include Decision Trees, Random Forests, Multilayer Perceptrons (MLPs), and Convolutional Neural Networks (CNNs).

The broader long-term objective of the project is to investigate how structured clinical records and medical imaging analysis may eventually be combined into unified machine learning diagnostic systems for liver disease assessment.
